# Быстрые команды · Quick commands

[Русский](#русский) · [English](#english)

---

## Русский

Быстрые команды (с версии 0.3.12) вставляют готовый текст по названию: подпись, реквизиты, адрес, номер договора,
шаблон ответа клиенту. Не нужно искать текст в заметках и копировать — достаточно назвать его голосом.

### Как добавить команду

1. Откройте настройки AitJaz (значок у часов → «Настройки» или пункт **«Быстрые команды…»**).
2. Слева выберите **«Быстрые команды»**.
3. В поле **«Название (что вы будете говорить)»** напишите, например, «Подпись рабочая» или «Реквизиты Народный банк».
4. В поле **«Текст, который вставится»** — сам текст. Можно в несколько строк.
5. Нажмите **«Сохранить команду»**. Чтобы добавить ещё одну — **«Новая команда»**, убрать — **«Удалить»**.

Команд может быть до 30. Они хранятся только на этом компьютере и никуда не отправляются.

### Как вставить

1. Поставьте курсор туда, куда нужен текст (письмо, документ, чат).
2. **Нажмите клавишу диктовки два раза коротко и быстро** (по умолчанию правый Ctrl). Рядом с текстовым курсором
   откроется список команд, первая подсвечена серым. Если программа, в которой вы пишете, не сообщает, где курсор,
   список откроется у указателя мыши.
3. Выберите команду одним из способов:
   - **Голосом.** Нажмите и держите клавишу, скажите название или номер. Отпустите клавишу — вставится текст
     найденной команды. Для русского, казахского, узбекского и кыргызского языка (распознавание на компьютере)
     серая подсветка переходит на команду прямо пока вы говорите; для других языков и при облачном распознавании
     команда находится, когда вы отпустите клавишу.
   - **Без голоса.** Каждое короткое нажатие клавиши двигает подсветку на следующую команду (после последней —
     снова к первой). Нажмите и чуть подержите клавишу — вставится подсвеченная.
   - **Мышью.** Наведите на команду и нажмите. Список не забирает курсор, текст вставится туда, где он стоял.

Вместо названия можно сказать номер из списка: «два», «второй», «2» (номера с 1 до 9).

Название можно сказать неточно: «реквизиты народного банка» найдёт «Реквизиты Народный банк». Если программа не
нашла такую команду, внизу списка появится «Не нашёл… Скажите ещё раз», и ничего не вставится.

Список закрывается клавишей **Esc**, крестиком «×» или сам через 20 секунд без действий.

В режиме «Нажать — старт, ещё раз — стоп» список открывается так же, двумя быстрыми нажатиями. Команду выбирают
голосом (нажать, сказать название, нажать ещё раз) или мышью.

## English

Quick commands (since 0.3.12) insert ready-made text by name: a signature, bank details, an address, a contract
number, a reply template. No need to search your notes and copy — just say its name.

### Add a command

1. Open AitJaz settings (tray icon → Settings, or **Quick commands…**).
2. Choose **Quick commands** on the left.
3. **Name (what you will say)**: for example "Work signature" or "Bank details".
4. **Text to insert**: the text itself; multiple lines are fine.
5. Click **Save command**. **New command** adds another one, **Delete** removes it.

Up to 30 commands. They are stored on this computer only and are never sent anywhere.

### Insert

1. Put the cursor where the text should go (email, document, chat).
2. **Press the dictation key twice, short and quick** (Right Ctrl by default). The list of commands opens next to
   the text cursor, with the first one highlighted in grey. If the app you are typing in does not report where the
   cursor is, the list opens next to the mouse pointer.
3. Pick a command in one of these ways:
   - **By voice.** Press and hold the key, say the name or number. Release the key and the matching command's
     text is inserted. For Russian, Kazakh, Uzbek and Kyrgyz (recognized on your computer) the grey highlight
     moves to the command while you are still speaking; for other languages and with cloud recognition the
     command is found when you release the key.
   - **Without voice.** Each short press of the key moves the highlight to the next command (after the last one it
     goes back to the first). Press and hold the key a moment to insert the highlighted one.
   - **With the mouse.** Point at a command and click. The list does not take the cursor, so the text goes where
     it was.

You can also say the number from the list: "two", "second", "2" (numbers 1 to 9).

The name does not have to be exact: a slightly different word form still finds the command. If no command
matches, "Couldn't find… Say it again" appears at the bottom of the list and nothing is inserted.

Close the list with **Esc**, with "×", or it closes by itself after 20 seconds of no activity.

In "Press to start, press again to stop" mode the list opens the same way, with two quick presses. Pick a command
by voice (press, say the name, press again) or with the mouse.
